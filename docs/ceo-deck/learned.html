Six pipelines over REGDOCS, July–October 2026, including a cloud build on 90,484 pages.

This is the sixth attempt since July to turn REGDOCS into trustworthy data, including a cloud build on Azure. They taught the same things. The worst failures are silent - every tool, cloud and local, lost or garbled text without saying so. We still have no hand-checked ground truth, so accuracy claims are machines agreeing. The first attempts built search and AI answers quickly, on text nobody had verified; it looked finished and was not. And lessons that were only written down were learned twice; only checks built into the process held. That is the case for a check at upload rather than a sentence in the manual. Extraction can recover much of the record, at a cost and never with certainty; the reliable fix is at the source.
