Found while collecting all 269,025 documents, July–October 2026.

Not every problem is the filer's. REGDOCS publishes no fingerprint for any file, so no one can prove a copy is the one filed. There is no bulk download or programmatic access: collecting the record meant crawling the website one request a second. Document type, company and filing exist only on web pages, not with the file. We found files served empty and forms served as web pages with broken images, the same file under several IDs, oversize drawings kept off the digital record, and documents cut into 20 MB pieces by the upload limit. These are the CER's own to fix, and they belong in the same Rules review.
